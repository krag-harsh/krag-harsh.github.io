Developed a neural network classifier to identify cuisine types from recipes, and an unsupervised ingredient substitution system using semantic embeddings — work done at the Complex Systems Lab, IIIT Delhi.

**Key contributions:**
- Neural network classifier for cuisine type identification from recipe text
- Unsupervised ingredient substitution via semantic embedding similarity
- 90% accuracy in cuisine preservation after cross-cultural transformation
